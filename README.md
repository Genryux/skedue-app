# Skedue

Skedue is a student productivity super app for managing subjects, schedules, notes, folders, and tasks in one place.

## Why this product exists

Students often split their school workflow across multiple apps:
- a calendar for schedules,
- a notes app for lecture content,
- a task app for deadlines,
- and sometimes messaging or file tools for sharing.

Skedue brings those pieces together around the student's actual academic structure: the subject.

## Core concept

Each subject acts as a hub where a student can:
- view schedule details,
- manage tasks,
- create notes,
- organize notes into folders,
- customize folder color,
- and share notes with others.

## Initial product direction

The first version should optimize for:
- fast subject setup,
- a clear today/this week schedule view,
- low-friction note creation,
- and a subject-centered workspace that reduces context switching.
